Project Backup Utility

A personal backup utility that creates encrypted snapshots on the account owner’s computer and copies them to that owner’s Google Drive.

This public website contains information only. It does not host project code, customer records, credentials, encryption keys or backup archives, and it has no upload or sign-in form.

How the utility works

  1. The owner selects local files and configuration for a snapshot.
  2. The utility encrypts the snapshot locally using AES-256-GCM.
  3. With the owner’s Google authorization, it uploads the encrypted archive to a private Drive folder.
  4. It checks the uploaded encrypted bytes against the local checksum before treating the upload as verified.

Access remains under the owner’s control

The Google Drive permission is limited to files created or explicitly opened through this utility. OAuth credentials remain on the owner’s computer. The backup encryption key is not uploaded with an archive.

The utility can include a stopped local database after confirming the relevant local services are stopped. It does not process payments or provide a public data service.
